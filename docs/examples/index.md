# Examples

Runnable examples live in the repository's `examples` directory. This section
will grow by provider and use case as more examples are added.

## Chat server

The current chat-server example is an AI SDK v7 conformance fixture. It
demonstrates the HTTP/SSE boundary and representative text, tool, approval, and
error event scenarios; it does not execute a real provider tool loop.

- [Chat server walkthrough](/guides/chat-server)
- [Source code](https://github.com/open-ai-sdk/ai-go/tree/main/examples/chat-server)

For smaller API-focused snippets, start with the [Quickstart](/getting-started)
and [Concepts](/core/).
