# Concepts

Concept pages explain the stable abstractions used across providers and
application workflows.

- [Providers and clients](/core/providers-and-clients) — provider-wide state,
  model handles, capabilities, and mixed-modality output.
- [Generate text](/core/generate-text) — the high-level generation workflow.
- [Direct completions](/core/completions) — one model call without tool-loop
  orchestration.
- [Streaming](/core/streaming) — normalized model and step events.
- [Structured output](/core/structured-output) — schema-backed Go values.
- [Tools](/core/tools) — typed tools, execution, and approvals.
- [Observability](/guides/observability) — provider-neutral tracing and content
  recording controls.

Provider-specific setup belongs under [Integrations](/integrations/), while
task-oriented walkthroughs belong under [Tutorials & Guides](/guides/).
